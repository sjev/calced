# Datetime Literals

2025-01-15 10:30                        # => 2025-01-15 10:30
2025-01-15 10:30:45                     # => 2025-01-15 10:30:45
2025-01-15 00:00                        # => 2025-01-15 00:00

# Seconds Are Hidden When Zero

2025-01-15 10:30:00                     # => 2025-01-15 10:30

# Time Arithmetic

2025-01-15 10:00 + 90 minutes           # => 2025-01-15 11:30
2025-01-15 10:00 - 30 minutes           # => 2025-01-15 09:30
2025-01-15 10:00 + 2 hours              # => 2025-01-15 12:00
2025-01-15 23:30 + 1 hour               # => 2025-01-16 00:30
2025-01-15 00:30 - 1 hour               # => 2025-01-14 23:30
2025-01-15 10:00:30 + 30 seconds        # => 2025-01-15 10:01

# A Time Unit Promotes a Plain Date

2025-01-15 + 3 hours                    # => 2025-01-15 03:00
2025-01-15 - 1 hour                     # => 2025-01-14 23:00

# Fractional Counts Truncate

2025-01-15 10:00 + 1.5 hours            # => 2025-01-15 11:00

# Calendar Units Keep the Time

2025-01-15 10:30 + 1 day                # => 2025-01-16 10:30
2025-01-31 10:30 + 1 month              # => 2025-02-28 10:30
2025-01-15 10:30 + 1 year               # => 2026-01-15 10:30
2025-03-29 12:00 + 1 day                # => 2025-03-30 12:00

# Compound Durations

2025-01-15 10:00 + 1 day + 30 minutes   # => 2025-01-16 10:30

# Datetime Differences Are Hours

2025-01-15 18:00 - 2025-01-15 09:00     # =>  9
2025-01-15 09:00 - 2025-01-15 18:00     # => -9
2025-01-15 10:30 - 2025-01-15 10:00     # =>  0.5
2025-01-16 - 2025-01-15 12:00           # => 12
2025-01-15 12:00 - 2025-01-15           # => 12

# Date Differences Stay Days

2025-01-16 - 2025-01-15                 # => 1

# Hours Feed Ordinary Math

(2025-01-15 18:00 - 2025-01-15 09:00) * 60              # => 540
(2025-01-15 18:00 - 2025-01-15 09:00) hours in minutes  # => 540

# Datetime Variables

start = 2025-01-15 09:00                # => 2025-01-15 09:00
finish = start + 8 hours                # => 2025-01-15 17:00
finish - start                          # => 8

# Datetimes Are Skipped in a Total

2025-01-15 10:00 + 1 hour               # => 2025-01-15 11:00 │
100                                     # => 100              │
200                                     # => 200              │
sum()                                   # => 300              ┘

# An Out-of-Range Time Is Not a Datetime

2025-01-15 25:00
2025-01-15 10:70

# A Bare Time Is Plain Text

meeting 10:00
standup at 09:30
